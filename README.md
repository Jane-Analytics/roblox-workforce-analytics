# Roblox Africa Operations - Workforce Analytics

# Project Overview
This capstone project consolidates 7 siloed HR datasets into a unified analytical platform for Roblox Africa Operations.

#Business Problem
Roblox Africa Operations lacked a single view of workforce costs, education-job placement, employee wellbeing risks, and department efficiency.

#Technology Stack
- Python 3.8+
- SQL, MySQL 8.0
- Pandas, SQLAlchemy, PyMySQL
- Streamlit, Plotly

# Key Findings
- $2.8M annual optimization opportunity identified
- 3 high-risk departments requiring immediate intervention
- 45% uninsured rate in Operations
- 22 days medical leave in IT (vs 12 avg)
- $800K inefficiency in Marketing compensation
